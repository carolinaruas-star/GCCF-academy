## 📚 Sobre a Academia

A **Google Cloud Computing Foundations Academy**, realizada em parceria com a **ACATE**, é uma jornada de formação voltada para o desenvolvimento de fundamentos essenciais em **computação em nuvem e Google Cloud**.

A academia combina conteúdos autoinstrucionais, sessões técnicas ao vivo e mentoria de carreira, proporcionando uma visão progressiva dos principais conceitos necessários para trabalhar com tecnologias de cloud.

A trilha aborda desde os **fundamentos de computação em nuvem** até temas de **infraestrutura, redes, segurança, dados, Machine Learning e Inteligência Artificial**.

---

## 🎯 Objetivo

Construir uma base sólida em **Cloud Computing e Google Cloud**, desenvolvendo conhecimentos técnicos que possam ser aplicados em projetos de:

* ☁️ Computação em nuvem;
* 🏗️ Infraestrutura cloud;
* 🌐 Networking;
* 🔐 Segurança;
* 📊 Dados e Analytics;
* 🤖 Machine Learning;
* 🧠 Inteligência Artificial.

Além da formação técnica, a academia também busca aproximar os participantes de **oportunidades profissionais no ecossistema Google Cloud**.

---

---

## 📖 Trilha de aprendizagem

### 01 — Google Cloud Computing Foundations: Fundamentos de Cloud

Introdução aos principais conceitos de **Cloud Computing**, modelos de serviço, infraestrutura em nuvem e fundamentos necessários para compreender o ecossistema Google Cloud.

### 02 — Google Cloud Computing Foundations: Infraestrutura no Google Cloud

Exploração dos principais componentes de infraestrutura do Google Cloud e dos recursos utilizados para construir e executar aplicações na nuvem.

### 03 — Google Cloud Computing Foundations: Networking & Security in Google Cloud

Estudo dos fundamentos de **redes e segurança**, incluindo conectividade, arquitetura de rede e conceitos essenciais para proteger recursos em ambientes cloud.

### 04 — Google Cloud Computing Foundations: Data, ML, and AI in Google Cloud

Introdução ao uso do Google Cloud para **dados, Machine Learning e Inteligência Artificial**, conectando os fundamentos de cloud às tecnologias modernas de dados e IA.
