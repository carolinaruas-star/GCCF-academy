## 📚 Sobre o curso

O **Fundamentos da computação do Google Cloud: noções básicas da computação em nuvem** é o primeiro curso da trilha **Google Cloud Computing Foundations**.

O curso apresenta os conceitos essenciais de **Cloud Computing** e introduz a forma como o **Google Cloud** pode ser utilizado para criar, executar e gerenciar aplicações e serviços na nuvem.

A formação é direcionada principalmente a pessoas com **pouca ou nenhuma experiência prévia em computação em nuvem**, servindo como base para os próximos cursos da trilha.

---

## 🎯 Objetivos

Ao concluir este curso, o objetivo é compreender:

* ☁️ O que é **computação em nuvem** e por que ela transforma tecnologia e negócios;
* 🏗️ As diferenças entre **arquiteturas tradicionais e arquiteturas em nuvem**;
* 📦 Os modelos de serviço **IaaS, PaaS e SaaS**;
* 🌐 As diferentes formas de interagir com o **Google Cloud**;
* 🖥️ As principais opções de **computação em nuvem**;
* 🗂️ O funcionamento de **projetos, recursos, APIs e permissões** no Google Cloud;
* 💻 O uso do **Cloud Console, Cloud Shell e Google Cloud CLI (`gcloud`)**.

Esses objetivos correspondem à proposta oficial do curso.

## 📖 Conteúdos principais

### ☁️ 01 — Computação em nuvem

Introdução aos fundamentos de Cloud Computing e comparação entre a infraestrutura tradicional e os ambientes baseados em nuvem.

Principais conceitos:

* Computação em nuvem;
* Arquitetura tradicional × cloud;
* IaaS;
* PaaS;
* SaaS;
* Arquitetura do Google Cloud.

---

### 🏗️ 02 — Plataforma Google Cloud

Conhecimento dos principais elementos necessários para começar a utilizar o Google Cloud.

Serão explorados:

* **Cloud Console**;
* Projetos;
* Recursos;
* IAM;
* Papéis e permissões;
* Faturamento;
* Cloud SDK;
* **Cloud Shell**;
* APIs do Google Cloud.

---

### 🖥️ 03 — Opções de computação

Introdução às diferentes formas de executar aplicações e workloads no Google Cloud.

Entre os principais serviços estudados estão:

| Serviço                      | Conceito principal                 |
| ---------------------------- | ---------------------------------- |
| **Compute Engine**           | Máquinas virtuais e IaaS           |
| **App Engine**               | Plataforma gerenciada e PaaS       |
| **Cloud Run functions**      | Funções orientadas a eventos       |
| **Google Kubernetes Engine** | Contêineres e orquestração         |
| **Cloud Run**                | Computação gerenciada e serverless |

O curso também aborda conceitos como **máquinas virtuais, escalonamento automático, aplicações elásticas, contêineres e computação serverless**.

## 🧪 Laboratórios práticos

Além das aulas conceituais, o curso inclui atividades práticas obrigatórias para aplicar os conhecimentos diretamente no ambiente Google Cloud.

### 🔹 Laboratório 01 — Um tour pelo Google Cloud

Exploração prática de:

* Projetos;
* Recursos;
* Usuários do IAM;
* Papéis;
* Permissões;
* APIs;
* Console do Google Cloud.

### 🔹 Laboratório 02 — Cloud Shell e `gcloud`

Prática com:

* Cloud Shell;
* Google Cloud CLI;
* Comandos `gcloud`;
* Conexão com recursos hospedados no Google Cloud.

### 🔹 Laboratório 03 — Criar uma Máquina Virtual

Utilização do **Compute Engine** para criar uma máquina virtual e explorar:

* Regiões;
* Zonas;
* Tipos de máquina;
* Recursos computacionais.

### 🔹 Laboratório 04 — App Engine: Qwik Start — Python

Criação e execução de uma aplicação simples utilizando o **App Engine**.

### 🔹 Laboratório 05 — Cloud Run functions

Criação e implantação de uma função utilizando o **Cloud Shell** e a linha de comando do Google Cloud.

### 🔹 Laboratório 06 — Google Kubernetes Engine

Introdução à implantação de uma aplicação conteinerizada utilizando o **Google Kubernetes Engine (GKE)**.
